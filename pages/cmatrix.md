# cmatrix

> Show a scrolling Matrix like screen in the terminal.
> See also: `neo`, `cbonsai`, `asciiquarium`, `pipes.sh`.
> More information: <https://manned.org/cmatrix>.

- Enable asynchronous scrolling:

`cmatrix -a`

- Change the text Color (green by default):

`cmatrix -C {{red}}`

- Enable rainbow mode:

`cmatrix -r`

- Use a screen update delay of 100 centiseconds (1 second):

`cmatrix -u 100`

- Use screensaver mode where the first keystroke exits:

`cmatrix -s`
